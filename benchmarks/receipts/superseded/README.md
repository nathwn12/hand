# Superseded benchmark receipts

These receipts were produced before the independent review fixes: they have no
browser-launch proof, no `SHA256SUMS` fixture pin, and no strict capture-evidence
fields. They are retained as history only and are excluded from the gate because
`compare.mjs` scans `benchmarks/receipts/`, not this subdirectory.

They are not current results and must not be cited as such.
